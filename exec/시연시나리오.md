# 시연 시나리오 — Hello World (SSAFY 15기 공통 PJT / E204)

시연 순서에 따라 **화면 → 클릭 위치 → 기대 결과**를 정리한다.
전체 소요 약 **7~8분**. 시간이 부족하면 ★ 표시 항목만 진행한다.

---

## 0. 사전 준비

| 항목 | 내용 |
|---|---|
| 접속 주소 | `http://localhost:3000` |
| 브라우저 | Chrome 최신 |
| 준비 계정 | ① 기존 계정(데이터 있음) ② 신규 가입용 이메일 ③ 다른 사용자 계정(팔로우·채팅 상대) |
| 기동 확인 | `docker compose ps` — 6개 컨테이너 `Up` |
| 주의 | `frontend/.env`의 `VITE_USE_MOCK`이 **`false`**인지 확인 (true면 목 데이터가 뜬다) |

> 채팅 시연은 **브라우저 두 개**(일반 창 + 시크릿 창)로 계정 두 개를 동시에 띄워두면 매끄럽다.

## 1. 회원가입 · 로그인 ★

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 1-1 | `/login` | 우측 하단 **회원가입하기** | `/signup`으로 이동 |
| 1-2 | `/signup` | 이메일·비밀번호 입력 → **회원가입** | 가입 완료 후 로그인 화면 |
| 1-3 | `/login` | 가입한 계정으로 **로그인** | 최초 로그인이면 `/settings/profile`로 이동 |
| 1-4 | — | (대안) **Google로 계속하기** | 구글 동의 화면 → 신규면 프로필 설정, 기존이면 피드 |

**설명 포인트** — 최초 로그인은 닉네임이 없어 프로필 설정으로 보낸다. Access Token은 메모리에만 두고 Refresh Token은 HttpOnly 쿠키로 관리한다.

## 2. 프로필 설정 (온보딩) ★

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 2-1 | `/settings/profile` | **이미지 올리기** → 파일 선택 | 원형 미리보기 갱신 |
| 2-2 | | **닉네임** 입력 | 저장 버튼 활성화 |
| 2-3 | | **한 줄 소개** 입력 | 우측 하단 글자 수 카운터 증가 |
| 2-4 | | 기술 스택 입력창에 `re` 입력 | 아래에 후보 목록(`React`, `Redis`) 표시 |
| 2-5 | | 후보 클릭 또는 **Enter** | 칩이 추가되고 카운터 `1 / 12` |
| 2-6 | | 하단 고정 바의 **저장** | `/users/me`로 이동 |

**설명 포인트** — 이미지는 저장을 눌러 확정하는 시점에만 업로드한다(고아 파일 방지). 기술 스택은 등록된 태그만 저장 가능해 입력 중 후보를 띄운다.

## 3. 프로필 화면 ★★ (핵심)

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 3-1 | `/users/me` | (진입 직후 **아무 조작 없이 2초 대기**) | 태그·업적 배지가 순차 등장 → 구분선이 좌우로 펴지며 GitHub 활동 → 게시글 섹션 |
| 3-2 | | 업적 배지 위에 **마우스 올리기** | 티어별 툴팁(골드는 콘페티) |
| 3-3 | | 배지의 **`+N` 타일**에 마우스 올리기 | 나머지 업적 목록 패널 |
| 3-4 | | GitHub 활동 영역 우측 **`잔디`** 클릭 | 53주 × 7일 격자로 전환 |
| 3-5 | | **`초원`** 클릭 | 캔버스 시각화로 복귀 |
| 3-6 | | 초원 위에서 **마우스 이동 / 길게 누르기** | 식물이 밀리는 반응 / 반딧불이가 모임 |
| 3-7 | | 통계 줄의 **팔로워** 클릭 | 팔로워 목록 모달 (URL도 함께 변경) |

**설명 포인트**
- 진입 애니메이션은 1350ms에 GitHub 활동, 1910ms에 게시글이 열리는 고정 타임라인이다.
- 초원은 최근 1년 커밋을 **식물 개수·키·밀도**로 환산해 그린다.
- GitHub 미연동 계정이면 같은 자리에 **연동 안내와 버튼**이 뜬다(3-8에서 시연).

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 3-8 | 미연동 계정의 `/users/me` | GitHub 활동 영역 | "GitHub을 연동하면 잔디를 볼 수 있어요" + 연동 버튼 |
| 3-9 | | **GitHub 연동** 클릭 | GitHub 승인 화면 → 승인 후 프로필로 복귀 + 성공 토스트 |

## 4. 게시물 작성 · 체험 ★★ (핵심)

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 4-1 | 좌측 레일 | **게시글 작성**(＋ 아이콘) | 작성 모달 |
| 4-2 | 모달 | **프로젝트** 탭 | 배포 URL·썸네일 입력란 |
| 4-3 | | GitHub 저장소 URL 입력 | AI 요약 생성(설정 시) |
| 4-4 | | **배포 URL** 입력 + **썸네일** 선택 | 게시 버튼 활성화 |
| 4-5 | | **게시** | 피드 최상단에 카드 등장 |
| 4-6 | 피드 | 방금 만든 카드 클릭 | 상세 모달 — **좌측에 프로젝트가 실제로 실행됨** |
| 4-7 | 상세 모달 | **좌측 영역 안에서 직접 조작** | 페이지를 떠나지 않고 체험 |
| 4-8 | | 우측 **댓글** 입력 → 등록 | 즉시 반영 (낙관적 업데이트) |
| 4-9 | | 우측 상단 **X** | 모달만 닫히고 피드 유지 |

**설명 포인트** — 이 화면이 서비스의 핵심이다. 링크로 내보내지 않고 **게시물 안에서 실행**해, 체험과 반응이 한 화면에서 일어난다. 임베드는 `sandbox` 속성으로 격리하고, 로드 실패 시 "새 창에서 열기" 폴백을 제공한다.

## 5. 좋아요 · 팔로우 (낙관적 업데이트) ★

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 5-1 | 피드 카드 | **하트** 클릭 | **즉시** 켜지고 숫자 +1 (서버 응답 대기 없음) |
| 5-2 | | 하트 **연타** | 상태가 꼬이지 않음 |
| 5-3 | 다른 사용자 프로필 | **팔로우** 클릭 | 즉시 "팔로잉"으로 전환, 팔로워 수 +1 |
| 5-4 | 좌측 레일 | **좋아요 목록** | 방금 누른 게시물이 목록에 존재 |

**설명 포인트** — 서버 응답을 기다리지 않고 화면을 먼저 바꾸고 실패 시 되돌린다. 좋아요 하나에 피드·상세·좋아요 목록 **세 곳**의 캐시를 함께 갱신한다. 연타해도 결과가 한 번 누른 것과 같도록 Redis에서 원자적으로 처리한다.

## 6. 실시간 채팅 · 알림 ★★

> 브라우저 두 개(A 계정 / B 계정)를 나란히 놓고 진행한다.

| # | 화면 | 클릭·입력 | 기대 결과 |
|---|---|---|---|
| 6-1 | A: B의 프로필 | **메시지 보내기** | 채팅방 생성·이동 |
| 6-2 | A: 채팅방 | 메시지 입력 → **Enter** | 즉시 말풍선 표시 |
| 6-3 | **B 화면** | (조작 없음) | **실시간 수신** + 좌측 레일 대화 뱃지 증가 |
| 6-4 | B | 대화 목록에서 방 클릭 | 뱃지 감소, 읽음 처리 |
| 6-5 | A: B의 게시물 | **좋아요** 클릭 | **B 화면**에 알림 뱃지 증가 |
| 6-6 | B: 좌측 레일 | **알림** 클릭 | 알림 목록에 항목 등장 |
| 6-7 | B | 알림 항목 클릭 | 읽음 처리 + 해당 게시물로 이동 |

**설명 포인트** — WebSocket(STOMP) 연결은 앱 전역에 하나만 유지하고, 채팅과 알림이 개인 큐 하나를 공유한다. 안 읽은 개수는 "1 증가"가 아니라 **"지금 N개"라는 최종값**으로 보내, 네트워크가 끊겨 한 번 놓쳐도 다음 이벤트에 자동 복구된다.

## 시연 중 주의사항

- **3-1은 반드시 조작 없이 기다린다.** 진입 애니메이션이 이 서비스의 인상을 만든다. 클릭하면 연출이 묻힌다.
- **4-6~4-7이 가장 중요하다.** 이 구간에서 시간을 아끼지 않는다.
- 배포 사이트가 임베드를 거부하면 흰 화면이 뜬다. **시연용 프로젝트는 사전에 임베드 동작을 확인**해 둔다.
- 채팅·알림은 두 화면을 **동시에 보여줘야** 실시간임이 전달된다. 화면 분할을 미리 잡아둔다.
- GitHub 연동은 승인 화면이 뜨므로 **미리 로그인**해 두면 흐름이 끊기지 않는다.

```
3-4  초원 ↔ 잔디 토글 (10초)
4-6  게시물 상세 — 프로젝트 실행 (40초)
4-7  직접 조작 (20초)
6-2  채팅 실시간 수신 (30초, 두 화면)
5-1  좋아요 즉시 반영 (10초)
```
